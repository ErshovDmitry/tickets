# Итоговый отчёт аудита tickets

Дата: 2026-09-06
Режим: read-only аудит, исходный код не изменялся.

## Общий результат

Baseline, тесты, race-проверки основных пакетов, cross-build Windows и сверка документации выполнены. Критичных проблем в файловых блокировках, TOCTOU-защите, атомарных операциях, архивировании как основном сценарии и разрешении путей не найдено.

## Найденные замечания

### 🔴 Высокий приоритет

1. **Многострочный title приводит к потере данных.**
   - Место: `internal/cli/cmd_new.go` / `internal/domain/markdown.go`.
   - Воспроизведение: создать тикет с `\n` в title, затем выполнить `set`. H1 парсится только до первой строки, остаток исчезает при рендеринге.
   - Рекомендация: отклонять `\r` и `\n` в title до создания файла; добавить regression-тест.

### 🟡 Средний приоритет

2. **ArchiveClosed игнорирует ошибки сканирования.**
   - Место: `internal/store/archive.go`, `ArchiveClosed`.
   - Рекомендация: обрабатывать `dirErr` и warnings; уже перемещённые файлы возвращать вместе с ошибкой.

3. **Create мутирует входной Ticket.**
   - Место: `internal/store/store.go`, `Create/createLocked`.
   - Рекомендация: либо использовать копию, либо явно зафиксировать mutation contract в публичной документации и тесте.

4. **Лишние positional arguments list игнорируются.**
   - Место: `internal/cli/cmd_list.go`.
   - Пример: `ticket list active extra` завершается успешно.
   - Рекомендация: отклонять более одного фильтра.

5. **Warnings list не влияют на exit code.**
   - Место: `internal/cli/cmd_list.go`.
   - Рекомендация: принять явную политику: tolerant mode с кодом 0 либо partial-failure с ненулевым кодом; документировать её.

### 🔵 Низкий приоритет

6. `cmd/ticket/main.go` имеет 0% покрытия; это приемлемо для thin wrapper, но можно добавить smoke-тест.
7. Windows runtime-тесты не исполняются на Linux; cross-build успешен, нужен Windows runner для полного smoke.
8. `Filename` не валидирует аргументы самостоятельно; защитить контракт тестами или добавить validating API.

## Положительные стороны

- Все текущие Go-тесты проходят.
- Race tests проходят для domain/store/lock/paths/cli.
- Есть защита от symlink/special-file и TOCTOU-подмены.
- Статус из имени файла правильно считается источником истины.
- Реализованы no-replace commits и rollback/error-path тесты.
- Windows amd64 cross-build успешен.
- Документация в целом соответствует реализации.
