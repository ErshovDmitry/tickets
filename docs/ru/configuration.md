# Конфигурация

Переменные окружения, которые задают, где `ticket` хранит данные, кого записывает автором и на каком языке говорит.

## Переменные окружения

| Переменная | Назначение |
|------------|------------|
| `TICKETS_DIR` | явный override каталога тикетов |
| `TICKET_WHO` | автор тикета; цепочка `TICKET_WHO → USER → USERNAME → agent` |
| `TICKET_LANG` | язык справки `ticket help` и файлов, создаваемых `ticket new`; цепочка `TICKET_LANG → LC_ALL → LANG`; известный префикс выбирает язык, неизвестный → EN, все пусты → RU (по умолчанию) |

Каждая цепочка вычисляется слева направо: побеждает первое непустое значение. `TICKET_WHO` откатывается к `USER`, затем к `USERNAME` (Windows), затем к литералу `agent`. `TICKET_LANG` откатывается к `LC_ALL`, затем к `LANG`. Его префикс (до первого `_` или `.`, без учёта регистра) выбирает известный язык; неизвестный префикс откатывается к английскому. Только когда все три пусты — используется русский (по умолчанию).

## Приоритет флага

Глобальный флаг `-C` / `--tickets-dir` перекрывает `TICKETS_DIR` на один вызов. Полный порядок резолюции каталога тикетов — в [installation.md](installation.md).

## Примеры

```bash
# один вызов против песочницы
ticket -C /tmp/sandbox/tickets list

# то же через окружение
TICKETS_DIR=/tmp/sandbox/tickets ticket list

# англоязычная справка
TICKET_LANG=en ticket help

# записать конкретного автора
TICKET_WHO=ivan ticket new "Экспорт падает" -t BUG -p high
```

Сборка бинаря и прогон тестов: [development.md](development.md).
